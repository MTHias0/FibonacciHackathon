# Trabalho atual

1. Na raiz do projeto, leia `AGENTS.md` (instruções) e `CONTEXTO.md` (estado).
2. **Ao retomar:** confira o `git status` e os arquivos citados. Se o estado real divergir do registro, corrija o `CONTEXTO.md` antes de continuar.
3. **Ao salvar:** releia o `CONTEXTO.md` e atualize as seções existentes (estado, decisões, pendências, próximo passo), mantendo o arquivo curto. Preserve o que os colegas registraram.
4. Novas regras permanentes de arquitetura vão para o `AGENTS.md`. Não duplique nada nesta skill.
