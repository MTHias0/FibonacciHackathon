## Recomendação

1. **Estado BR → SP pelo `ctresb/leis/estaduais/SP`.** É a mesma origem e a mesma licença de Birigui, com o frontmatter quase igual. Para a demo, comece pela Constituição SP (notas `(NR)`/"redação dada" ricas) e por um recorte de leis. O histórico git não serve como linha do tempo de alterações aqui.
2. **Município → Fortaleza** (capital, Lei Orgânica compilada com notas de emenda, 773 leis, adaptador SAPL já existente). Alternativa maior: Porto Velho. A pasta `municipais/SP/sao-paulo` só tem a LO e 1 decreto. Ranking parcial: a árvore `municipais/` veio truncada pela API.
3. **EUA → DC Code (`DCCouncil/law-xml-codified`)**: o único estadual/distrital com licença aberta, histórico git real e notas de alteração por lei. O custo é o parser XML. Se só der tempo para "EUA" com esforço baixo, `legalize-us` (federal) entra pelo adaptador `es`.
